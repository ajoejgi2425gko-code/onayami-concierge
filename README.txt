AI相談キャラクリエイト v39

【使い方】
1. 悩みを書く
2. キャラを選ぶ：おすすめ6種類、オリジナルキャラ、または全24種類
3. 「オリジナルキャラ」を選ぶと名前・性格・画像を入力できます。入力内容は選択カードとプレビューに反映されます。
4. 相談文を作成して外部AIへコピーしてください。画像はAIに送信されません。

【保存について】
キャラは保存しなくても使えます。次回も使う場合だけ「キャラを保存・呼び出す」を開いて手動保存してください。JSONバックアップはその他の管理にあります。保存データはブラウザ内で管理します。

【GitHub Pages公開】
ZIP内の31ファイルをリポジトリの公開フォルダ直下に配置してください。既存の全ファイルを上書きしてください。

公開後、オリジナルキャラ選択→名前・性格・画像反映→相談文生成→保存→再読み込み→呼び出し→JSONバックアップ・復元、Android PWA更新を実機で確認してください。

【v39更新】

[v39] かんたん設定にも相談相手の性別選択を常時表示。キャラ別に名前・性格・性別・話し方・距離感の編集中設定を保持。保存済みキャラを読み込むと編集中の保持情報は切り替わります。保存操作の詳細説明は保存管理欄にまとめました。

【v39】悩みの一時保存は自動保存から明示的な保存ボタン方式に変更。保存はタブ内のsessionStorageで、タブ終了後の永続性は保証されません。おすすめ設定復帰後の相談文更新警告、新規キャラ編集中の保存済みキャラ切り替え確認を修正。

【v39の変更】
・相談テーマ・悩み本文・時期・気持ち・状況をボタン操作で一時保存／復元。保存後の変更検知も全項目に対応。
・先生、恋人、年上の恋人、人生のパートナー、長年連れ添った配偶者は性別の指定に応じて既存のイラストを切り替えます。画像の見た目は役割に近い既存キャラからの流用です。
・キャラの保存（localStorage）と相談内容の一時保存（sessionStorage）は別々です。

【v39】役割・年代・雰囲気に合わせて性別別画像の割り当てを再確認。親友・兄姉・弟妹・先輩・カウンセラー風にも対応。相談内容の一時保存が長期保管ではないことを明記。

【v39の変更】中性的な画像の一律割り当てを廃止し、役割に合う場合だけ性別画像を切り替えます。性別別画像の重複を減らしました。「おすすめ6種類に戻す」では選択中のキャラを維持し、そのカードだけ追加表示します。キャラ保存と相談内容の一時保存の対象をボタン名に明記しました。

【v39】選択キャラ変更時のおすすめ一覧再描画。相談目標・追加指示・確認質問も一時保存。人生のパートナーに女性画像追加。父母・祖父母・彼氏彼女・夫妻の性別を固定し選択欄を非表示。その他は性別を選択可能で、対応画像があれば切り替え。
