AI相談キャラクリエイト v8
GitHub Pagesの既存リポジトリのルートにZIP内のファイルをすべて上書きしてください。
以前のv4のキャラ保存データは同じブラウザ・同じURLで引き続き読み込めます。
保存済みキャラを選択するとキャラ設定と引き継ぎメモを自動復元します。
メモ編集は保存済みキャラを選んだ状態なら自動保存。初回は「このキャラを保存」を押してください。
実際のAI会話は自動取得されません。引き継ぎメモは利用者が記入・更新します。

【v6更新】希望する対応・話し方・回答に含めることの選択肢を拡充。引き継ぎは必要なときだけ利用し、現在のAIに要約依頼文をコピーできるようにしました。

【v7更新】引き継ぎ依頼文のコピー成功時はボタンが「✓ コピーしました！」に変わり、次の操作を常時案内します。コピー失敗時は失敗を明示し再試行できます。

【v8更新】相談キャラに恋人・彼氏・彼女・年上の恋人・夫・妻・人生のパートナー・長年連れ添った配偶者を追加。距離感にも恋人・夫婦向けの選択肢を追加。恋愛・結婚、夫婦・パートナーの相談テーマは従来から選択可能です。

【v9更新】相談相手を選ぶと性別・距離感のおすすめを自動設定。どちらも手動変更可。オリジナル入力の優先を明確化。保存済みキャラを呼び出した際は保存内容を尊重。
