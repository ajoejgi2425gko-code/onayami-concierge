AI相談キャラクリエイト v18

GitHub Pagesの公開フォルダ直下にZIP内の31ファイルをすべてアップロードしてください。

更新内容：初回3ステップの説明改善、キャラごとのおすすめ相談表示、性別・距離感・話し方の固定切替（保存・バックアップ対応）、こだわり設定のステップ番号修正、コピー後案内修正、画像付き設定ファイルの検証改善。

画像は外部AIに自動送信されません。ブラウザ内保存は容量制限があります。保存済みキャラは従来のキーを継続利用します。

公開後はブラウザでキャラ変更、保存・復元、PWA更新を確認してください。

【v19変更点】
・かんたん設定の3ステップ案内を明確化。こだわり設定では6ステップの案内に切り替え。
・設定固定をこだわり設定内に移し、表現を簡潔に変更。
・保存画像の復元に失敗した場合はメッセージを表示。JSON読み込みの文字数検証を追加。
・キャラ返答例は実際のAIの出力を保証しない旨を明示。
・v18の既存保存データ形式を維持。


v20 修正：画像アップロード直後のプレビュー表示、既存キャラを選択した場合のオリジナル名解除、容量不足時の具体的対処案内。

公開前の実機確認：
1. 画像アップロード直後にプレビューへ表示されるか。
2. オリジナル名を入力後、既存キャラを選ぶと既存キャラに切り替わるか。
3. 画像付きキャラを保存→再読み込み→呼び出し→JSON書き出し→読み込みできるか。
4. 同じ悩みで親友・先生・AI相談パートナーを選び、ChatGPT・Gemini・Copilotで話し方の差を比較する（外部AIの応答は保証できません）。
