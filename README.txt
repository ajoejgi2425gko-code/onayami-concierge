AI相談キャラクリエイト v35

【使い方】
1. 悩みを書く
2. キャラを選ぶ：おすすめ6種類、オリジナルキャラ、または全24種類
3. 「オリジナルキャラ」を選ぶと名前・性格・画像を入力できます。入力内容は選択カードとプレビューに反映されます。
4. 相談文を作成して外部AIへコピーしてください。画像はAIに送信されません。

【保存について】
キャラは保存しなくても使えます。次回も使う場合だけ「キャラを保存・呼び出す」を開いて手動保存してください。JSONバックアップはその他の管理にあります。保存データはブラウザ内で管理します。

【GitHub Pages公開】
ZIP内の31ファイルをリポジトリの公開フォルダ直下に配置してください。既存の全ファイルを上書きしてください。

【v29更新】
・24種類と同じキャラ選択一覧にオリジナルキャラを追加。おすすめ6種類の表示中も選択可能。
・オリジナルキャラ選択時のみ名前・性格・画像の入力欄を表示。入力に応じて選択カード・プレビューを更新。
・既存キャラからオリジナルキャラに切り替える際、性別・距離感・話し方は標準設定から開始（固定設定時を除く）。
・保存は手動。バックアップ操作を「その他の管理」に整理。
・古い自動保存の説明を修正。

【動作確認】
公開後、オリジナルキャラ選択→名前・性格・画像反映→相談文生成→保存→再読み込み→呼び出し→JSONバックアップ・復元、Android PWA更新を実機で確認してください。

【v29】保存したキャラは選択画面の「保存したキャラ」に表示され、タップで呼び出せます。24種類それぞれに任意の名前を付けて個別保存できます。同じ名前で保存すると上書き確認が表示されます。

【v31更新】
・保存した既存キャラを種類優先で復元し、オリジナルキャラの入力履歴が混ざらないよう修正。
・既存キャラの任意名をプレビューに「名前（種類）」として表示。
・未保存の変更がある場合のみ、保存済みキャラへの切り替え時に確認。
・保存済みキャラは最初の6件を表示し、残りは展開。
・オリジナルキャラでは名前入力欄を1つに整理。
・保存は手動です。既存24種類それぞれの名前も個別に保存できます。

【v35更新】
・キャラを切り替えても、種類ごとの入力途中の性格を維持します。オリジナルの名前と画像も維持します。
・保存済みキャラは選択画面から呼び出し、管理欄は保存・削除・バックアップ用に整理しました。
・保存済みキャラの件数（最大30件）を表示します。画像によっては件数上限より先にブラウザの保存容量が不足します。
・削除・全件削除後に未保存状態を正しく同期します。
・動作確認推奨：性格入力→キャラ切替→戻る、保存→削除→再保存、画像付きキャラの保存・復元、PWA更新。

[v35] かんたん設定にも相談相手の性別選択を常時表示。キャラ別に名前・性格・性別・話し方・距離感の編集中設定を保持。保存済みキャラを読み込むと編集中の保持情報は切り替わります。保存操作の詳細説明は保存管理欄にまとめました。

【v35】悩みの一時保存は自動保存から明示的な保存ボタン方式に変更。保存はタブ内のsessionStorageで、タブ終了後の永続性は保証されません。おすすめ設定復帰後の相談文更新警告、新規キャラ編集中の保存済みキャラ切り替え確認を修正。
