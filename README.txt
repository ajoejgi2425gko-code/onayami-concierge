AI相談キャラクリエイト v18

GitHub Pagesの公開フォルダ直下にZIP内の31ファイルをすべてアップロードしてください。

更新内容：初回3ステップの説明改善、キャラごとのおすすめ相談表示、性別・距離感・話し方の固定切替（保存・バックアップ対応）、こだわり設定のステップ番号修正、コピー後案内修正、画像付き設定ファイルの検証改善。

画像は外部AIに自動送信されません。ブラウザ内保存は容量制限があります。保存済みキャラは従来のキーを継続利用します。

公開後はブラウザでキャラ変更、保存・復元、PWA更新を確認してください。

【v19変更点】
・かんたん設定の3ステップ案内を明確化。こだわり設定では6ステップの案内に切り替え。
・設定固定をこだわり設定内に移し、表現を簡潔に変更。
・保存画像の復元に失敗した場合はメッセージを表示。JSON読み込みの文字数検証を追加。
・キャラ返答例は実際のAIの出力を保証しない旨を明示。
・v18の既存保存データ形式を維持。


v20 修正：画像アップロード直後のプレビュー表示、既存キャラを選択した場合のオリジナル名解除、容量不足時の具体的対処案内。

公開前の実機確認：
1. 画像アップロード直後にプレビューへ表示されるか。
2. オリジナル名を入力後、既存キャラを選ぶと既存キャラに切り替わるか。
3. 画像付きキャラを保存→再読み込み→呼び出し→JSON書き出し→読み込みできるか。
4. 同じ悩みで親友・先生・AI相談パートナーを選び、ChatGPT・Gemini・Copilotで話し方の差を比較する（外部AIの応答は保証できません）。

【v22の改善】
・既存キャラを選択中は既存キャラ画像を優先。アップロード画像は独立した確認欄で表示し、オリジナル名入力時だけメインプレビューへ反映。
・オリジナルキャラの話し方・距離感・性別は現在の設定を引き継ぐことを明記。
・かんたん設定からも保存・バックアップ欄を直接開けるショートカットを追加。
・相談文生成後の「作る→コピー→AIで貼り付ける」手順を視覚化。
・PWAキャッシュをv22に更新。

【v22での修正】
・かんたん設定でも「キャラ設定をファイル保存」「設定ファイルを読み込む」を表示します。
・入力リセットでアップロード済みオリジナル画像も解除します。保存済みキャラは削除しません。
・画像付きキャラの保存・JSON書き出し・読み込みを実際のブラウザで確認することを推奨します。

【v23の改善】
・重複していた「同じ悩みでも、キャラで返事はこんなに変わる」を削除。キャラ選択時の個別返答例は維持。
・保存済みキャラは選択しただけでは読み込まず、「呼び出す」ボタンで反映。
・JSON書き出しは「現在のキャラ1件」のみであることを明記。
・入力リセット時に悩みの一時保存データと保存設定も削除。保存済みキャラは維持。
・実際の外部AIの返答差はサービスごとに異なり、未検証。

【v24の変更】
・端末内保存とJSONバックアップ（現在のキャラ1件）の目的をボタン・説明で区別。
・JSON読み込み後、端末内に保存するための案内を強調。
・「悩みだけ消す」と「すべての入力をリセット」を分離。前者はキャラ設定と画像を保持。
・外部AIでのキャラ回答の再現性は利用サービスに依存します（未検証）。

[v25] 相談内容のみの削除対象をテーマ・背景等へ拡大。JSON読込後に保存ボタンを表示。名前変更時の未保存表示を追加。

[v26] トップの古いバージョン表記を削除。保存状態を「保存済み／変更を保存中／未保存の変更あり／保存できませんでした」に整理。保存済みキャラを呼び出していない状態で別キャラを上書きしないよう自動保存を制御。一時保存データ削除時に一時保存設定のオン・オフを案内。

【実機での確認推奨】
1. キャラを保存→設定変更→自動保存→再読み込み→呼び出して内容を確認
2. キャラ名変更→「未保存」表示→手動保存→再読み込み
3. 保存済みキャラ選択だけでは編集内容が切り替わらないことを確認
4. JSONファイル読込→端末に保存→再読み込みで復元
5. オリジナル画像付きキャラの保存・復元とPWAの更新
6. 一時保存オンのまま相談内容を削除→新しい悩みの入力で再保存されることを確認

【v27の変更】
・オリジナルキャラの性格をかんたん設定でも入力可能に。
・キャラの作成と保存を分けて説明し、画像設定は折りたたみ。
・自動保存を廃止し、明示的な「この端末にキャラを保存」に統一。
・保存済みキャラ選択時は読み込み操作まで反映しない。
・相談内容削除時のsessionStorage例外を処理。
